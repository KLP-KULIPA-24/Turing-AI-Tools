FAQ

常见问题

脚本如何工作？
通过内置油猴引擎监听网页对话流，一处接入大模型 API，自动生成伪装回复并实时分析对手，判定真人/ AI 后自动点击结算按钮。
支持哪些设备？
目前仅适配电脑端客户端：Windows 10 / Windows 11 系统上的 Chrome / Edge / Firefox 浏览器（安装 Tampermonkey「篡改猴」或 Violentmonkey「暴力猴」扩展即可）。手机、平板、Mac、Linux 暂不支持，OpenSERP 搜索后端也是 Windows 的可执行程序。
支持哪些浏览器和网站？
Chrome / Edge / Firefox 等主流浏览器，安装 Tampermonkey（篡改猴）或 Violentmonkey（暴力猴）任一款扩展即可。支持「任意门 · 图灵测试」（anyanygame.com）和「更好的图灵测试」（xfcode.top）两个网站。
如何开启联网搜索？
zip 内自带后端搜索服务：解压后双击运行「启动联网搜索后端服务器.py」（需装 Python 3），会自动在 127.0.0.1:7070 启动 OpenSERP 服务；然后在脚本参数里打开「联网搜索」即可，无需额外配置。
需要服务器或数据库吗？
断言与自动回复逻辑全部在浏览器本地执行，战绩与配置仅保存在你自己的浏览器存储中；联网搜索功能默认关闭，如开启需配合 zip 内附带的 OpenSERP 后端服务（双击「启动联网搜索后端服务器.py」即可启动）。API Key 只保存在你的浏览器里。
首次使用如何配置？
安装后打开图灵测试页面，按 Insert 键展开控制台（或点击右下角浮动按钮「TUI」），切换到 API配置 页填写一个 OpenAI 兼容接口地址和 Key（默认 https://api.agnes-ai.cn/v1），回主面板打开「自动回复」即可。
会一局结束后自动再来一局吗？
会。开启全自动匹配后，无论获胜 / 失败 / 平局，结算页出现"再来一局"按钮都会自动点击，无限连战。
